# AMCAT-DATA-ANALYSIS-
Project Overview
This project performs an extensive Exploratory Data Analysis (EDA) on the AMCAT (Aspiring Minds Computer Adaptive Test) dataset. The analysis focuses on 3,998 engineering graduates to identify the key factors—such as education, location, and technical scores—that influence salary and employability in the Indian job market.

Key Features & Contributions
Comprehensive EDA: Analyzed a dataset of 3,998 engineering graduates using Python’s data science stack.

Data Cleaning: Handled missing values, standardized categorical features, and resolved inconsistencies across 38+ features, including education details, job city, and standardized test scores.

Salary Insights: Identified an average annual salary of approximately 3.07 LPA, with detailed distribution analysis across different academic backgrounds.

Market Trends: Discovered Bangalore as the leading hiring hub (680 records) and Software Engineer as the most prevalent job role (539 entries).

Visualizations: Created correlation matrices and distribution plots to visualize how employability scores (AMCAT) impact salary growth.

Tech Stack
Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Environment: Jupyter Notebook

Dataset Highlights
The dataset includes critical information such as:

Personal Data: Gender, DOB, and Home State.

Academic Scores: 10th/12th percentages, Degree, and Specialization.

Employability Scores: AMCAT scores in Cognitive, Technical, and Personality domains.

Employment Details: Job City, Designation, and Salary (CTC).

Visualizations & Insights
Salary Distribution: Right-skewed distribution indicating a concentration of entry-level roles.

Top Cities: Strong geographical preference for Tier-1 cities like Bangalore, Noida, and Hyderabad.

Skill Correlation: Analyzed how technical modules correlate with the final CTC offered to candidates.
